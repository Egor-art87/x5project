# HR Platform Frontend (X5 Tech Team)

Это фронтенд-приложение для HR-платформы, разработанное на React + TypeScript. Проект представляет собой пользовательский интерфейс для взаимодействия кандидатов с системой подбора персонала, включая регистрацию, прохождение тестов, выбор вакансий и отслеживание статуса откликов.

Приложение реализовано в виде одностраничного интерфейса (SPA) с навигацией между основными разделами через верхнее меню. В шапке сайта расположены ключевые страницы: «Главная», «Тесты», «Вакансии», «Отклики» и «Профиль».

Главная страница содержит приветственный блок с текстом «Работай с нами X5 Tech Team», а также блок с новостями компании. Дополнительно реализована кнопка входа/регистрации, которая открывает модальное окно с полупрозрачным фоном. В форме регистрации пользователь вводит ФИО, контактные данные, дату рождения и гражданство.

Страница «Вакансии» позволяет пользователю выбрать интересующее направление. Представлены категории: разработка (Frontend, Backend, Fullstack, Mobile, GameDev, Embedded), данные (Data Science, Data Analyst, ML, Data Engineering), инфраструктура (DevOps, SRE, Cloud, System Administration), продукт и дизайн (UX/UI, Product), бизнес и маркетинг (Marketing, Sales, HR и др.), а также QA (Manual и Automation). Выбор вакансии влияет на дальнейшее прохождение тестирования.

Страница «Тесты» содержит набор вопросов и ситуационных задач. Вопросы направлены на оценку таких характеристик, как инициативность, структурность мышления, адаптивность, стрессоустойчивость, командная роль и подход к решению задач. Перед прохождением теста пользователь должен выбрать вакансию.

Страница «Отклики» отображает список кандидатов и их текущий статус. Для каждого пользователя могут отображаться такие состояния, как: прошёл/не прошёл тестирование, отклонён или находится в процессе рассмотрения. Также может отображаться дополнительная информация о кандидате.

Страница «Профиль» содержит информацию о пользователе, введённую при регистрации, а также аватар. Если пользователь не авторизован, происходит редирект на форму регистрации. В случае отсутствия изображения используется стандартная иконка (голова и плечи).

Проект использует строгую типизацию TypeScript и настроен с ESLint для поддержания качества кода. В кодовой базе запрещено использование типа `any`, применяется явная типизация данных и компонентов. Также используется корректная типизация стилей через `React.CSSProperties`.

Структура проекта организована по принципу разделения на компоненты и страницы. Основные директории: `components` (переиспользуемые элементы интерфейса) и `pages` (страницы приложения). Точка входа — `App.tsx`, где настраивается маршрутизация.

Перед запуском необходимо установить зависимости командой `npm install`, затем запустить проект через `npm run dev`. Для корректной работы важно, чтобы в проекте отсутствовали дублирующиеся директории и конфликты конфигурации TypeScript.

Проект ориентирован на дальнейшую интеграцию с backend-сервисом, включая обработку тестов с помощью AI-агента и хранение данных пользователей.

Дизайн интерфейса выполнен в зелёной цветовой гамме с использованием градиентов и акцентом на тёмно-зелёные оттенки, что соответствует стилистике X5 Tech.
